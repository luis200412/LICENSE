# Business Website Starter

This repository now includes a simple public website ready for GitHub Pages.

## Included files

- `/home/runner/work/LICENSE/LICENSE/index.html` — homepage
- `/home/runner/work/LICENSE/LICENSE/robots.txt` — crawl rules
- `/home/runner/work/LICENSE/LICENSE/sitemap.xml` — sitemap for indexing
- `/home/runner/work/LICENSE/LICENSE/.github/workflows/pages.yml` — automatic deployment

## Make it your own

1. Edit `index.html` with your real:
   - Business name
   - Services
   - Contact details
2. Replace placeholder metadata values (`Your Business Name`, `you@example.com`) in `index.html`.
3. If your site URL changes, update:
   - Canonical URL and Open Graph URL in `index.html`
   - Sitemap URL in `robots.txt`
   - `<loc>` in `sitemap.xml`

## Publish publicly

1. Ensure the default branch is `main`.
2. In GitHub repository settings, open **Pages** and set **Source** to **GitHub Actions**.
3. Push changes to `main`; the workflow deploys automatically.
